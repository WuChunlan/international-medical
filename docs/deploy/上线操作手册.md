# 国际医疗平台 — 上线操作手册（按顺序照做）

> 本手册是**操作 runbook**：从买完服务器到正式上线，一条线走完，照着敲即可。
> 原理、选型、为什么这么选 → 见同目录《部署操作文档.md》。本手册只讲"现在做什么"。
>
> 系统：Alibaba Cloud Linux 3（RHEL 系，用 `dnf`）。命令已按此适配。
> 部署形态：一台香港服务器，同时跑 Nginx + 后端 JAR + MySQL + Redis，靠域名区分 site-a 与 admin。

---

## 0. 开始前：把这些值替换掉（全文统一）

照做时先把下面这些占位符换成你的真实值，全文出现的地方一并替换：

| 占位符                             | 换成                     | 从哪拿                         |

| `换强密码_REDIS`                   | Redis 密码               | 自己设，强密码                 |
| `换成JWT随机串`                    | JWT secret               | `openssl rand -base64 48` 生成 |
| `noreply@example.com` / 邮箱授权码 | 真实发信邮箱             | 你的邮件服务商                 |

> 约定（已按你的域名填好）：`www.scohospital.com` = 宣传站 site-a（海外）；`admin.scohospital.com` = 后台 admin（国内运营）。

**本项目关键事实（照做时会用到，已核对代码）：**

- 数据库脚本：结构 `schema_v3.sql`，基础数据 `data.sql`，可选 `taikang-tongji-seed.sql` / `xianlin-gulou-seed.sql`

## 时间线总览（谁卡谁）

```
今天先做 ┬ 阶段0-A 下单服务器 ──────────► 拿到公网 IP
         └ 阶段0-B 买域名 + 提交实名 ──► 实名审核几小时~1天（全程最慢，先启动）
                    │
    （实名审核期间同时做）阶段2 服务器装环境
                    ▼（实名通过）
         阶段1 配 DNS 解析（3条A记录，几分钟生效）
                    ▼
         阶段3 数据库 + 后端上线
                    ▼
         阶段4 前端上线 + HTTPS
                    ▼
         阶段5 安全加固 + 验证清单
```

**并行技巧**：实名审核最慢。今天就先下单服务器 + 提交域名实名，然后趁审核期做阶段 2（装环境），两者互不依赖。

## 阶段 1：配 DNS 解析（实名通过后，浏览器 2 分钟）

阿里云域名控制台 → 你的域名 → **解析** → 添加 3 条 A 记录（`1.2.3.4` 换成真实 IP）：

- [ ] `www` → A → `1.2.3.4`，TTL 10 分钟
- [ ] `@` → A → `1.2.3.4`，TTL 10 分钟
- [ ] `admin` → A → `1.2.3.4`，TTL 10 分钟

在**本地 Mac** 验证：

```bash
dig www.scohospital.com +short     # 应输出 1.2.3.4（你已验证通过 ✅）
dig admin.scohospital.com +short   # 应输出 1.2.3.4
```

> CDN 先不接。先用 A 记录直连把站跑通，上线稳定后再回头接 Cloudflare（见《部署操作文档.md》4.6）。

### 3.4 ⚠️【图片/视频上传核心】修 `site_config` 表 + 建目录

图片、视频上传全部由 `site_config` 表这 5 个配置项驱动（已核对 `FileUploadService.java`）。种子数据里它们还是 **Mac 路径 + localhost + 50MB 小上限**，不改则：**图片打不开、视频直接传不上去**。

**① 先看现状：**
```bash
mysql -u intlmed -p international_medical -e \
"SELECT config_key,value_zh FROM site_config WHERE config_key LIKE 'upload_%';"
```
| config_key | 种子默认值 | 问题 |
|---|---|---|
| `upload_base_path` | `/Users/wuchunlan/Desktop/医疗平台媒体资源` | ❌ Mac 路径，Linux 上不存在 |
| `upload_base_url` | `http://localhost:8080/media` | ❌ localhost+http，外网打不开 |
| `upload_max_size_mb` | `50` | ❌ **视频几百 MB 会被拒**，这是视频传不上去的根因 |
| `upload_allowed_image_types` | `jpg,jpeg,png,webp,gif` | ✅ 够用 |
| `upload_allowed_video_types` | `mp4,mov,avi,webm` | ✅ 够用，缺格式再加 |

**② 一次性改好（视频上限设 2048MB，与 Spring 上限对齐）：**
```bash
mysql -u intlmed -p international_medical
```
```sql
UPDATE site_config SET value_zh='/data/uploads/media', value_en='/data/uploads/media'
  WHERE config_key='upload_base_path';
UPDATE site_config SET value_zh='https://www.scohospital.com/media', value_en='https://www.scohospital.com/media'
  WHERE config_key='upload_base_url';
UPDATE site_config SET value_zh='2048', value_en='2048'
  WHERE config_key='upload_max_size_mb';
-- 需要更多视频格式（如 mkv）再执行：
-- UPDATE site_config SET value_zh='mp4,mov,avi,webm,mkv', value_en='mp4,mov,avi,webm,mkv'
--   WHERE config_key='upload_allowed_video_types';
EXIT;
```

**③ 建上传目录并授权**（`FileUploadService` 会自动按分类建子目录如 `hospitals/videos`、`doctors/photos`，你只需建好根目录）：
```bash
mkdir -p /data/uploads/media
chown -R deploy:deploy /data/uploads
chmod -R 755 /data/uploads
```

> ⚠️ **三层大小限制，缺一不可**（否则大视频某一层被卡）：
> | 层 | 位置 | 需设为 | 本手册对应 |
> |---|---|---|---|
> | 应用层 | DB `upload_max_size_mb` | 2048 | 本节 ② |
> | 框架层 | `application.yml` `max-file-size` | 已是 2048MB | 源码已配，无需动 |
> | 网关层 | Nginx `client_max_body_size` | 2100m | 阶段 4.3 |

> ⚠️ **`upload_base_path` 只在后端启动时读取一次**（见 `WebMvcConfig`）。所以：**先把 3.4 的 DB 改完，再启动/重启后端**（3.7）。若你已启动过后端，改完这里必须 `systemctl restart intlmed-backend` 才生效。

### 3.6 写生产配置（服务器）

先生成 JWT secret：`openssl rand -base64 48`，复制输出填到下面 `jwt.secret`。

新建 `/opt/intlmed/config/application-prod.yml`：
```yaml
server:
  port: 8080
spring:
  servlet:
    multipart:
      max-file-size: 2048MB       # 视频上限，与 DB upload_max_size_mb 对齐
      max-request-size: 2048MB
  datasource:
    url: jdbc:mysql://localhost:3306/international_medical?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Hong_Kong&allowPublicKeyRetrieval=true&useSSL=false
    username: intlmed
    password: 换强密码_DB
  data:
    redis:
      host: localhost
      port: 6379
      password: 换强密码_REDIS
  mail:
    host: smtp.你的邮件服务商.com
    port: 587
    username: noreply@scohospital.com
    password: 换成邮箱授权码
jwt:
  secret: 换成JWT随机串
  expiration: 86400000
  admin-expiration: 28800000
app:
  cors:
    allowed-origins:
      - https://www.scohospital.com
      - https://scohospital.com
      - https://admin.scohospital.com
  mail:
    from: noreply@scohospital.com
    verify-code-ttl: 600
    verify-code-resend-interval: 60
```
收紧权限：
```bash
chmod 600 /opt/intlmed/config/application-prod.yml
chown deploy:deploy /opt/intlmed/config/application-prod.yml
```

### 3.7 注册 systemd 服务并启动

新建 `/etc/systemd/system/intlmed-backend.service`：
```ini
[Unit]
Description=International Medical Backend
After=network.target mysqld.service redis.service

[Service]
User=deploy
WorkingDirectory=/opt/intlmed
ExecStart=/usr/bin/java -Xms512m -Xmx2g \
  -Dspring.profiles.active=prod \
  -Dspring.config.additional-location=/opt/intlmed/config/ \
  -jar /opt/intlmed/app.jar
SuccessExitStatus=143
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
> ⚠️ `-Dspring.profiles.active=prod` 与 `-Dspring.config.additional-location=...` 两行都不能删，否则退回硬编码 `root/123456` + localhost CORS。

```bash
systemctl daemon-reload
systemctl enable --now intlmed-backend
systemctl status intlmed-backend       # 应为 running
journalctl -u intlmed-backend -f        # 连库/Redis 成功、无报错
```
检查：
- [ ] 服务 running，日志无 SQL/Redis 报错
- [ ] `curl http://localhost:8080/api/config/list` 或任一公开 GET 接口有返回

### 4.3 Nginx 站点配置

> Alibaba Cloud Linux 走 `/etc/nginx/conf.d/*.conf`。新建 `/etc/nginx/conf.d/intlmed.conf`：

```nginx
# ---------- 宣传站 site-a：www + 裸域 ----------
server {
    listen 80;
    server_name www.scohospital.com scohospital.com;
    root /var/www/site-a;
    index index.html;
    client_max_body_size 2100m;    # 放开大视频上传（对齐 2GB）

    location / { try_files $uri $uri/ /index.html; }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;        # 大文件上传耗时，超时放宽
        proxy_send_timeout 300s;
    }
    location /media/ {                  # 图片/视频对外访问
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location ~* \.(js|css|png|jpg|jpeg|gif|svg|woff2?)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
}
# ---------- 后台 admin ----------
server {
    listen 80;
    server_name admin.scohospital.com;
    root /var/www/admin;
    index index.html;
    client_max_body_size 2100m;

    location / { try_files $uri $uri/ /index.html; }
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
    location /media/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
```bash
rm -f /etc/nginx/conf.d/default.conf    # 移除默认站点
nginx -t && systemctl reload nginx
```

## 出问题先查这里

| 现象 | 原因 | 解决 |
|------|------|------|
| **视频上传报"文件大小超过限制 50MB"** | DB `upload_max_size_mb` 没改 | 见 3.4 ② 改成 2048 后**重启后端** |
| **视频上传报 413** | Nginx `client_max_body_size` 太小 | 4.3 设 `2100m` 后 reload |
| **图片/视频传成功但打不开(404)** | `upload_base_path`/`upload_base_url` 没改，或后端没重启 | 见 3.4，改完 `systemctl restart intlmed-backend` |
| 图片 URL 还是 `localhost:8080` | `upload_base_url` 没改 | 见 3.4 ② |
| 大视频上传中途断 | 反代超时 | 4.3 已设 `proxy_read/send_timeout 300s`，仍不够可调大 |
| 前端调接口报 CORS | prod 配置没生效 | 确认 systemd 有 `-Dspring.profiles.active=prod`；CORS 填正式域名后重启 |
| 刷新前端子路由 404 | 缺 SPA 回退 | Nginx `try_files $uri /index.html` |
| 后端连不上库 | 密码/账号错 | 核对 `application-prod.yml`，看 `journalctl -u intlmed-backend` |
| 验证码异常 | Redis 密码不一致 | 确认 `redis.conf` 与 `application-prod.yml` 密码相同 |
